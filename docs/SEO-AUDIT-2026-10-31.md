# SEO and browser audit — 31 October 2026

Scope: https://akaa.dev/; homepage HTML, crawler metadata, robots/sitemap,
private routes/404 behavior, desktop/mobile browser, and fixture-backed admin/contact flows.
Original design, content identity and social preview artwork retained.

## Findings and changes

- The server-rendered favicon was fixed to the default even after an admin change.
  Render the published favicon URL and matching MIME type in the first response.
- Custom social images inherited JPEG/1200×630 metadata. Resolve absolute URLs,
  infer known MIME types, and declare dimensions only for known bundled assets.
  Synchronize Open Graph secure_url and Twitter image after client-side changes.
- Remove duplicate Person aliases without adding the previously removed alias.
- Keep hero identity and lead text visible from first render instead of fading them
  back out when the browser starts. Pause background glow animation offscreen.
- Serve the same Plus Jakarta Sans variable font locally, with a font preload,
  swap rendering and its OFL license. Eliminate the external Google Fonts CSS chain.
- Lazy-load below-fold project thumbnails; keep profile image high priority.
- Include visible ID/EN text in the language button accessible name.

## Verification

TypeScript, production build, 21 backend/routing/mail tests and 8 desktop/mobile
Playwright tests pass. Browser tests include navigation/focus, contact validation,
all AdminDashboard tabs, draft preview, publishing and language/theme controls.
Admin/contact mutations use fixtures, not real visitor messages or admin passwords.
Dependency audit: zero known vulnerabilities at inspection time.

Live baseline browser checks: one H1, no horizontal overflow, no broken loaded
images, no page JavaScript errors, canonical https://akaa.dev/, readable identity
with JavaScript disabled. Automated WCAG A/AA checks in inspected default desktop
and mobile states found no violations; this is not an accessibility certification.

Baseline Lighthouse simulated mobile: performance 46, accessibility 100,
best practices 100, SEO 100; FCP 3.0s, LCP 5.0s, TBT 1060ms. Lighthouse also
identified a language-button accessible-name issue outside its weighted score.
Lab scores vary with server/network/CPU and do not establish field Core Web Vitals
or ranking. Post-deploy measurements are stored separately in the audit workspace.

## Search Console and limitations

The connected domain property covers subdomains too. For 2–29 October, returned
page rows were for aio-dl.akaa.dev, not the portfolio homepage; do not attribute
those rows to the portfolio or infer that the homepage is unindexed. This connector
cannot submit indexing requests or inspect Google's chosen canonical/index status.

Current public HTML contains the full name, school and PMR context and excludes
the removed alias. Robots/sitemap are publicly available; social preview is the
existing 1200×630 lightweight JPEG. Some external project links could not be
verified because the execution network returned proxy 403 responses; these were
not classified as broken or removed. No invented achievements or keyword-stuffed
content were introduced. Search ranking and Google's favicon refresh are external
and cannot be guaranteed by deployment or Lighthouse scores.
